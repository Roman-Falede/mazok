# Мазок 3 — нативная версия на Rust

Та же программа для рисования, переписанная на Rust: без браузера и WebView, одним файлом для Windows и нативной библиотекой для Android.
Интерфейс — [egui](https://github.com/emilk/egui) (OpenGL), всё рисование, слои, режимы наложения и форматы файлов — собственный код на Rust.

## Установка

- **Windows — `dist/rust/Mazok.exe`** (≈6 МБ). Установка не нужна: просто запустите. Нужна видеокарта с OpenGL 3.
  Рисунки и настройки хранятся в `%APPDATA%\Mazok`.
- **Android — `dist/rust/Mazok.apk`** (≈6 МБ). Android 8.0 и новее, 64-битный процессор ARM (почти все телефоны и планшеты с 2017 года).
  Ставится отдельно от прежней версии (пакет `app.mazok.rs`), поэтому старые рисунки сначала экспортируйте из прежней версии.
  Экспорт сохраняет картинки в «Галерею» (Pictures/Мазок), остальное — в «Загрузки»/Мазок.

## Что есть

- **Галерея**: холсты по шаблонам или своего размера, автосохранение (а также при сворачивании окна), переименование, дублирование, удаление, импорт PNG/JPEG/PSD/.mazok (на компьютере).
- **Два интерфейса**: настольный в стиле фоторедактора (меню, панель параметров, инструменты слева, док «Цвет/Образцы», «Кисти/Настройки кисти», «Слои/История», строка состояния) и сенсорный для телефонов с плавающими окнами и вертикальными ползунками. Выбор — автоматически по ширине окна или в «Настройках».
- **Кисти**: 80 встроенных кистей в 9 наборах (эскиз, тушь, живопись, аэрограф, текстура, природа, декор, пиксель, свои), 26 форм отпечатка, 7 текстур зерна, образцы штрихов в списке.
- **Настройки кисти**: форма, жёсткость, интервал, округлость, угол, поворот по штриху; колебания размера, угла, прозрачности и цвета; рассеивание; текстура; поток; сглаживание штриха и сужение концов; нажим пера; режим «свечение»; пиксельная кисть. Свои кисти, дубликаты, сброс к исходным.
- **Инструменты**: кисть (с режимом наложения), ластик, палец, штамп, заливка с допуском (тяните вбок), градиент (4 вида), пипетка (удержание, Alt, правая кнопка), выделение (прямоугольник, эллипс, лассо, волшебная палочка; добавить, вычесть, пересечь, инвертировать, растушевать), перемещение и трансформация (масштаб, поворот, отражение), текст (системные шрифты), фигуры (прямоугольник, эллипс, линия, многоугольник, звезда), рука, масштаб.
- **Быстрые фигуры**: задержите перо в конце штриха — линия, круг или многоугольник.
- **Слои**: 27 режимов наложения (сохраняются в PSD), непрозрачность, обтравочные маски, защита прозрачности, блокировка, референс-слой для заливки, текстовые слои, объединение, сведение, цвет и видимость фона.
- **Фильтры**: тон/насыщенность, яркость/контраст, цветовой баланс, карта градиента, обесцвечивание, инверсия, постеризация, порог, размытие по Гауссу, в движении, радиальное, резкость, шум, свечение, хроматическая аберрация, полутон, пикселизация, виньетка — с предпросмотром.
- **Помощники**: сетка и симметрия (вертикальная, горизонтальная, квадранты, радиальная).
- **Экспорт**: PNG, JPEG, PSD со слоями (сжатие RLE, фон — отдельным слоем), .mazok, слои в PNG (ZIP), GIF.
- **Управление**: нажим пера, жесты (2 пальца — отмена, 3 — повтор, 4 — скрыть панели, щипок — масштаб и поворот), горячие клавиши («Справка»), светлая и тёмная тема, масштаб интерфейса, история с переходом к любому шагу.

Формат `.mazok` совместим с веб-версией: проекты открываются в обеих.

## Чего пока нет по сравнению с веб-версией

Анимация и таймлапс, экспорт видео и WebP, пластика, кривые, искажение и деформация при трансформации, перспективные направляющие, цветовые гармонии, форма отпечатка и зерно из своих картинок, импорт/экспорт кистей. На Android пока нельзя открыть файл из памяти телефона (импорт), а ввод текста идёт через системную клавиатуру NativeActivity — с некоторыми клавиатурами кириллица может не вводиться.

## Сборка

```
rust/build-exe.ps1                     Mazok.exe  (Rust + Visual Studio Build Tools с C++)
rust/android/build-apk.ps1 -Sdk <SDK>  Mazok.apk  (Rust + цель aarch64-linux-android, JDK 17+,
                                                   в SDK: build-tools, platforms/android-35, ndk/<версия>)
```

APK подписывается тем же ключом, что и прежняя версия (`build/android/mazok-release.keystore`).
Если путь к проекту длинный или с кириллицей, задайте короткий `CARGO_TARGET_DIR` (например `C:\mazok-target`) — иначе компоновщик Windows может не найти файлы.

**Автотест интерфейса.** Задайте `MAZOK_AUTOTEST` (папка для отчёта) и `MAZOK_DATA` (временная папка данных) и запустите exe: программа сама нарисует штрихи мышью, применит заливку, фигуры, фильтры и текст, проверит отмену и сохранение в PNG/JPEG/PSD/.mazok/GIF, сделает скриншоты всех экранов и закроется. Итог — в `log.txt`.

## Структура

```
src/main.rs, lib.rs   запуск на Windows и Android
src/app.rs            галерея, хранение, автосохранение, экспорт, команды
src/ui.rs             меню, панели, док, галерея, диалоги, иконки
src/editor.rs         холст, ввод (мышь, перо, жесты), инструменты, выделение, трансформация, история
src/brush.rs          движок кистей, отпечатки, зерно, сглаживание, быстрые фигуры, симметрия
src/doc.rs            документ, слои, композитинг, история изменений
src/blend.rs          27 режимов наложения
src/raster.rs         растровые операции: заливка многоугольников, размытие, заливка области, аффинные преобразования
src/filters.rs        фильтры и коррекция
src/formats.rs        ZIP, PNG, JPEG, PSD, GIF, .mazok
src/state.rs          настройки, цвета, палитры, библиотека кистей
src/platform.rs       диалоги файлов (Windows), MediaStore (Android), шрифты
src/autotest.rs       автотест интерфейса
src/presets.json      встроенные кисти
android/              манифест и сборка APK
```
