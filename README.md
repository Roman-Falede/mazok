# Мазок — приложение для цифрового рисования (Windows и Android)

Самостоятельная программа для рисования с набором возможностей уровня профессиональных планшетных редакторов.
Код, интерфейс, кисти и иконки — оригинальные. Работает без интернета, рисунки хранятся на устройстве.

> **Новое: Мазок 3 на Rust** — нативная версия без браузера и WebView (`dist/rust/Mazok.exe`, `dist/rust/Mazok.apk`).
> В 3.2: слои как в Clip Studio Paint — папки, перетаскивание, маски, выбор нескольких слоёв, черновые слои.
> В 3.1: вставка картинок по Ctrl+V, сохранение в выбранные папки, векторные слои с ластиком «до пересечения», импорт кистей Photoshop (.abr) и Clip Studio (.sut), палитры, стабилизатор.
> Описание, сборка и отличия от веб-версии — в [rust/README.md](rust/README.md). Ниже описана веб-версия (v2).

## Установка

**Windows — `dist/Mazok.exe`**
- Запустите `Mazok.exe`: программа предложит установиться (ярлыки в «Пуске» и на рабочем столе, запись в «Установленных приложениях», удаление там же). «Нет» — запуск без установки.
- Работает на встроенном в Windows 10/11 движке Edge WebView2. Рисунки хранятся в `%LOCALAPPDATA%\Mazok\data`.

**Android — `dist/Mazok.apk`**
- Скопируйте файл на телефон и откройте его; разрешите установку из этого источника. Нужен Android 7.0 или новее.
- Экспорт сохраняет картинки в «Галерею» (Pictures/Мазок), видео — в Movies/Мазок, остальное — в «Загрузки»/Мазок.

**Без установки**
- Дважды щёлкните `Запустить Мазок (Windows).bat` — откроется отдельное окно приложения (через Microsoft Edge), или откройте `index.html` в браузере.

## Пересборка exe и apk

- `build/windows/build-exe.ps1` — нужен .NET Framework 4.8 (есть в Windows) и файлы WebView2 SDK в `build/windows/sdk`.
- `build/android/build-apk.ps1` — нужен JDK 17+, Android build-tools 35 и `android.jar` платформы 35 в `build/android/sdk`.
- Ключ подписи APK создаётся при первой сборке: `build/android/mazok-release.keystore` и `keystore.password`. **Сохраните их** — обновления APK должны подписываться тем же ключом.

**Android и полноценная установка как приложения (PWA)**
1. Разместите папку `mazok` на любом HTTPS-хостинге (GitHub Pages, Netlify, Cloudflare Pages — бесплатно).
2. Откройте адрес в Chrome на Android → меню ⋮ → «Установить приложение». На Windows в Edge/Chrome: значок «Установить» в адресной строке.
3. После первого открытия приложение работает офлайн, со своей иконкой и в отдельном окне.
4. Нужен APK-файл? Вставьте адрес сайта в pwabuilder.com — он соберёт пакет для Android (и MSIX для Windows / Microsoft Store).

Резервная копия рисунка: «Действия → Экспорт → Мазок (.mazok)». Файл можно открыть на другом устройстве через «Импорт» в галерее.

## Возможности

- **Два интерфейса**: настольный (строка меню, панель параметров инструмента, панель инструментов слева, док справа: Цвет/Образцы, Кисти/Настройки кисти, Слои/История, строка состояния) и планшетный для телефонов. Переключение: «Окно» или «Настройки».
- **Галерея**: создание холстов (шаблоны и свой размер), импорт PNG/JPEG/PSD/.mazok, переименование, дублирование, удаление, автосохранение.
- **Кисти**: 80 встроенных кистей в 8 наборах (эскиз, тушь, живопись, аэрограф, текстура, природа, декор, пиксель) + свои кисти; 27 форм отпечатка.
- **Настройки кисти** прямо в панели: форма, динамика формы, рассеивание, текстура, передача, динамика цвета, сглаживание и сужение, перо и нажим; режим наложения кисти.
- **Новые инструменты**: градиент (линейный, радиальный, зеркальный, угловой), фигуры (прямоугольник, эллипс, линия, многоугольник, звезда), рука, масштаб.
- **Студия кистей**: интервал, сглаживание (StreamLine), сужение концов, форма отпечатка (в т. ч. из своего изображения), зерно/текстура (в т. ч. своя), жёсткость, угол, поворот по штриху, разброс, колебания размера/прозрачности/цвета, давление и наклон пера, пиксельный режим, режим «свечение», блокнот для пробы, импорт/экспорт кистей.
- **Инструменты**: кисть, палец (растушёвка), ластик — каждый со своей кистью и размером; заливка с порогом (тяните вбок), заливка перетаскиванием цвета на холст; пипетка (удержание, Alt, ПКМ); клонирование.
- **Быстрые фигуры**: задержите перо в конце штриха — линия, эллипс/круг, треугольник, прямоугольник, многоугольник, ломаная.
- **Слои**: до сотни слоёв (зависит от памяти), 27 режимов наложения (в т. ч. растворение, линейный затемнитель, яркий/линейный/точечный свет, жёсткое смешение, вычитание, разделить — все сохраняются в PSD), непрозрачность, обтравочные маски, защита прозрачности, блокировка, референс-слой, объединение, сведение, дублирование, перетаскивание, цвет фона, текстовые слои.
- **Выделение**: прямоугольник, эллипс, лассо (свободное и по точкам), автовыделение с порогом; добавить/вычесть, инвертировать, растушевать, копировать и вставить.
- **Трансформация**: свободная, пропорциональная, искажение (перспектива), деформация (сетка), отражение, поворот на 45°, по размеру холста, сглаживание.
- **Коррекция** (на слой или кистью): тон/насыщенность/яркость, цветовой баланс, кривые, карта градиента, размытие по Гауссу, в движении, радиальное, резкость, шум, свечение, хроматическая аберрация, полутон, пикселизация, виньетка, обесцвечивание, инверсия, постеризация, порог; **пластика** (толкать, вихрь, сжать, расширить, кристаллы, сгладить, восстановить).
- **Цвет**: круг, квадрат, гармонии (дополнительный, расщеплённый, аналоговый, триада, тетрада), значения HSB/RGB/HEX, палитры (свои, из изображения, из холста), недавние цвета.
- **Помощник рисования**: сетка, изометрия, перспектива с 1/2/3 точками схода, симметрия (вертикальная, горизонтальная, квадранты, радиальная) и притягивание линий.
- **Анимация**: слои как кадры, луковая кожура, воспроизведение (цикл/пинг-понг/один раз), FPS, первый кадр как фон; экспорт GIF, MP4/WebM, кадров PNG.
- **Таймлапс**: автоматическая запись процесса, просмотр, экспорт видео (полностью или 30 секунд).
- **Экспорт**: PNG, JPEG, WebP, PSD со слоями, .mazok, слои PNG в ZIP; «Поделиться» на Android.
- **Холст**: обрезка и изменение размера, поворот, отражение, зеркальный вид, окно-образец, сведения о холсте, отмена до сотен шагов.
- **Управление**: перо с нажимом и наклоном, жесты (2 пальца — отмена, 3 — повтор, 4 — скрыть интерфейс, щипок — масштаб и поворот), горячие клавиши (список — «Действия → Справка»), светлая/тёмная тема, режим для левши.

## Чего пока нет

3D-раскраска моделей, группы слоёв и маски слоёв, импорт наборов кистей из других программ, длительность отдельных кадров анимации, запись таймлапса в 4K.

## Структура

```
index.html, css/app.css     интерфейс
js/brushes.js               движок кистей, зерно, быстрые фигуры
js/engine.js                слои, композитинг, история, выделение
js/tools.js                 инструменты, трансформация, пластика
js/adjust.js                фильтры и коррекция
js/formats.js               ZIP, PSD, GIF, видео
js/gallery.js, js/app.js    галерея, сохранение, анимация, таймлапс, запуск
sw.js, manifest.webmanifest офлайн-режим и установка
```
